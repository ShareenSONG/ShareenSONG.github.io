# 第一阶段设计方向：把消费电子的“元气感”转译为个人作品集

> 状态：设计方向已完成，尚未进入网页实现。
>
> 输入：个人简历、经历目录、主张证据账本与 Youdoo 高精度复刻提示词。
>
> 结构化蓝图：`design/phase-1-blueprint.json`。

## 1. 这份提示词真正定义了什么

提示词要求的不只是黄色、圆角和大图，而是一套完整的消费电子官网叙事方式：先用一整屏建立情绪与记忆点，再通过大幅媒体、滚动场景、轮播和少量文字逐层解释产品价值。视觉优先级高于信息密度，图片和动效承担主要表达。

个人网站不应复制 Youdoo 的产品、儿童家庭、购买和客服内容；应该高精度继承它的比例、节奏与交互语法，再把语义替换为宋艾欣的身份、作品、决策和证据。最终效果应像一位有鲜明产品感的 AI 产品经理官网，而不是黄色版在线简历。

## 2. 参考站实测观察

本轮实际检查了 [Home](https://youdooplay.com/)、[News](https://youdooplay.com/News/)、[Support](https://youdooplay.com/Support/) 和 [About](https://youdooplay.com/AboutUs/)。以下数字来自 2026-09-03 的浏览器渲染，仅作为后续设计基准；原站更新后可能变化。

### 桌面端 1440 × 900

| 对象 | 实测特征 |
| --- | --- |
| 全局容器 | 主宽度 1180px，左右约 130px |
| Header | 1180 × 56px，距顶部 24px，固定定位，全圆角黄色胶囊 |
| Home Hero | 900px，等于一整个视口高度 |
| Hero 字体 | 主标题 72/72px、700；副标题 32/32px、700 |
| 首页大卡片 | 约 1200 × 675px，24px 圆角 |
| News Hero | 1180 × 445px，24px 圆角，图片上覆盖深色遮罩 |
| News Grid | 四列，每列 285px，14px gap；图片 285 × 213px、14px 圆角 |
| Support 布局 | 280px 侧栏 + 885px 内容区 |
| Support 卡片 | 双列，约 403 × 332px，16px 圆角，20px 内边距 |
| About 正文 | 800px 阅读宽度，顶部 180px 留白，正文 16px |

### 移动端 390 × 844

- Header 为 360 × 56px，左右约 11px，距顶部 24px。
- 桌面导航收起为 Logo + 紫色圆形 Hamburger。
- Hero 仍占完整一屏 844px，而不是压缩成普通 Banner。
- Hero 主标题降为 40/40px，副标题 15px。
- 普通章节标题约 26px；大场景标题仍可能达到 68px。
- 产品主视觉从右侧并列改为文字下方的大幅纵向构图。

### 动效与滚动

原站实际加载 Lenis、Swiper、GSAP 和 ScrollTrigger，并使用：

- 黄色品牌加载页；
- 固定胶囊 Header；
- 0.48 秒的导航文字翻转 Hover；
- 100vh 产品图与自动静音视频；
- Sticky/Pinned 滚动章节；
- 径向游戏轮盘；
- 横向无缝图片带；
- 点评轮播与淡入弹窗。

值得借鉴的是“物理感”和章节节奏，而不是把所有动效都搬进个人网站。过多 Pinned 场景会让作品集难以快速浏览，因此首页只保留一组核心滚动叙事，移动端全部恢复自然文档流。

## 3. 个人品牌方向

### 定位

**宋艾欣 / Shareen Song — AI 产品经理**

建议的核心表达：

> 把复杂 AI 能力，做成可验证的产品闭环。

这句话同时覆盖了简历中最强的三个特征：产品研究与定义、AI Agent 与异常边界、真实业务交付。

### 气质

- 清醒：不夸大 AI 能力，能说清规则、模型与人工边界。
- 有行动力：从研究、PRD 到原型、Dashboard 与交付都有产物。
- 好奇：经历横跨体感硬件、Agent、安全、心理健康与零售。
- 有温度：心理协会、古筝、瑜伽、书法和社区活动提供人感。
- 可信：量化主张与证据状态分开管理。

### 视觉关键词

`Playful precision / Bright / Rounded / Editorial / Product-minded / Human`

“Playful”来自黄色和互动，“precision”来自网格、证据标签与克制排版。两者必须同时存在，否则容易变成儿童品牌或普通科技模板。

## 4. 视觉系统

### 色彩

| Token | 建议色值 | 用途 |
| --- | --- | --- |
| Signal Yellow | `#FFDF00` | Header、标签、关键 CTA、旗舰场景 |
| Ink | `#131924` | 标题、按钮、主要正文 |
| Canvas | `#F7F8FA` | 页面底色 |
| Paper | `#FCFAFB` | Hero 与大幅媒体背景 |
| White | `#FFFFFF` | 卡片与正文区域 |
| Violet Scene | `#8547FF` | 一至两个沉浸案例场景 |
| Coral Scene | `#FF8A65` | 教育/人文案例的暖色辅助 |
| Muted Ink | `#5E6470` | 次要文本 |

黄色是识别色，但不能从头铺到尾。建议大部分页面保持白/浅灰，黄色承担 15%–25% 的视觉面积；紫色只作为明确章节背景，不做泛滥的“AI 蓝紫渐变”。

### 字体层级

- 中文优先：HarmonyOS Sans SC / PingFang SC。
- 英文与数字：Inter 或系统无衬线字体。
- Desktop Hero：72px，紧凑行高，700。
- Desktop Section：56–90px 响应式范围。
- Mobile Hero：40px；普通章节标题 32px。
- 正文：桌面 16px / 1.6，移动 15px / 1.65。

标题应短而有冲击力，长解释进入正文或案例页。避免一屏同时出现多段简历式 bullet。

### 形状与空间

- Header：999px 胶囊圆角。
- 大幅媒体：24px。
- 普通卡片：16px。
- 图片：14px。
- 桌面主容器：1180px；宽媒体允许 1200px。
- 桌面标准章节垂直留白：96–160px。
- Hero 和关键案例允许 100svh。

## 5. 页面信息架构

### `/` 首页

目标是在 90 秒内完成“认识人 → 理解定位 → 看见证据 → 进入案例 → 联系”的闭环。

1. **Hero**：姓名、岗位、核心主张与人物主视觉。
2. **工作方式短片**：发现问题 → 定义边界 → 搭建流程 → 验证结果。
3. **旗舰项目**：竞品 Agent、iGarden、AI 数字人教育三个全屏案例。
4. **双重视角**：产品判断 × AI 构建。
5. **证据系统**：事实与证据 × 边界与兜底。
6. **经历时间线**：工作与教育的四个关键节点。
7. **网站之外的我**：社区、研学与长期兴趣。
8. **联系 CTA**：从“购买”语义转为“共同做有用的产品”。

### `/work` 项目

采用 Support 页的“侧栏 + 双列卡片”骨架，并叠加 News 页的筛选能力。类别建议为：工作项目、AI 产品、研究与验证、技术项目、全部。移动端侧栏变为顶部横向筛选。

### `/work/[slug]` 案例详情

统一结构：背景与问题 → 我的角色与边界 → 研究与约束 → 关键决策 → 方案与流程 → 验证与证据 → 结果 → 复盘。

案例页需要显式区分“已上线、已验证、方案阶段、团队成果、个人贡献、待补证”，这是本站相较普通作品集最有价值的可信度设计。

### `/notes` 随笔

沿用 News 的大图 Hero、筛选条与四列卡片。内容可承载 AI 产品观察、Agent 实践、用户研究、研学札记和活动复盘。首期没有文章时不要放空列表，可先隐藏入口。

### `/about` 关于

沿用 800px 编辑型阅读宽度与大留白，写“为什么从计算机与数据走向 AI 产品”，再补时间线、国际交流和个人兴趣。这里不重复整份简历。

## 7. 动效原则

- Header 继承 0.75 秒弹性宽度变化和 0.48 秒导航翻转，但控制反弹幅度。
- Hero 只做一次分行进入和主视觉错层，不做永不停歇的漂浮。
- 首页最多一组 Pinned 案例场景，避免滚动疲劳。
- 普通 Reveal 使用 600ms、20px 内的纵向位移。
- 卡片 Hover 只改变图片缩放、阴影和箭头位置。
- 轮播必须支持鼠标拖拽、触控和键盘。
- `prefers-reduced-motion` 下关闭 Pinned、Parallax、自动轮播和大幅 Transform。

加载页只作为可选品牌细节：若使用，必须基于真实资源加载状态、只在首次访问出现，并能在约 700ms 内跳过；不要伪造长时间 0–100% 进度。

## 8. 响应式策略

| 范围 | 设计变化 |
| --- | --- |
| ≥1440px | 1180px 主容器、全屏场景、Pinned 案例、四列内容卡片 |
| 1024–1439px | 32–48px 留白、三列卡片、减少媒体叠层 |
| 768–1023px | 两列卡片、侧栏转顶部筛选、缩短 Sticky 场景 |
| 375–767px | 16px 留白、单列内容、40px Hero、自然滚动、全屏菜单 |

移动端不是桌面端 `flex-wrap` 的结果。主视觉顺序、标题长度、案例呈现和动效模式都需要单独设计。

## 9. 素材盘点

### P0：进入线框前必须准备

1. 可抠图的自然半身肖像，长边至少 2400px。
2. 竞品 Agent：脱敏 Dashboard、工作流、证据链和异常案例。
3. iGarden：研究框架、产品生态图、核心流程和控制 App 原型。
4. AI 数字人教育：界面、部署或宣讲现场，移除客户敏感信息。

### P1：用于增强气质

1. 10–15 秒项目蒙太奇及静态 Poster。
2. VibeCoders、欧洲研学和校园活动照片。
3. 古筝、瑜伽或书法照片。
4. `SA / SHAREEN` 姓名字标。

本阶段没有下载 Youdoo 资源。后续即使为内部视觉研究保存参考素材，也应与最终网站素材严格分开，不能把 Youdoo Logo、吉祥物、产品图或家庭场景图作为个人网站资产发布。

## 10. 第一阶段决策与下一步

本阶段确定：

- 网站采用“明亮消费电子 + 编辑型作品集”方向。
- 黄色保留为候选主色，黑、白、浅灰构成基础系统。
- 首页用三个 S 级案例承担核心证明，不平铺全部 18 项经历。
- Support 的页面骨架转译为项目页，News 转译为随笔页，About 保留长文结构。
- 证据状态和贡献边界会成为案例设计的一部分。

下一阶段应先确认首页受众与黄色主色，再完成桌面/移动线框和 P0 素材可公开性盘点；仍不急于写组件。
