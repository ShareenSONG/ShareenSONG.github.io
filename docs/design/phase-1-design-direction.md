# 第一阶段风格设计：SOFT IRIDESCENT EDITORIAL

> 状态：已基于 10 页《个人网站参考素材》PPT 与 `02.png`—`06.png` 代表图重新校准。本轮只确认视觉方向，不修改网站、不进入页面实现。
>
> 核心原则：明亮留白承载信息，柔和虹彩负责氛围，深灰与深紫建立结构；所有不规则图形都必须保持连续、圆润、舒展。
>
> 视觉依据：`design/个人网站参考素材.pptx`、`design/02.png`、`design/03.png`、`design/04.png`、`design/05.png`、`design/06.png`。

## 1. 本轮校准结论

上一版把 PPT 中的“不规则”误读成了“尖锐”，使用多边形轮廓表达彩色形状，造成了明显的折角、锐边和攻击感。这与参考素材的真实气质相反。

PPT 的核心不是暗黑电影感，也不是霓虹科技感，而是一套 **SOFT IRIDESCENT EDITORIAL（柔光虹彩编辑感）** 视觉系统：

- 页面基底明亮、克制，留白占主导。
- 彩色部分像柔软的流体、丝带、薄膜或漫射光，不像箭头、碎片或尖刺。
- 形状虽然不对称，但轮廓由连续曲线和大圆弧组成，转折处保持顺滑的切线关系。
- 深灰文字与深紫标题提供理性和专业度，虹彩只负责情绪与识别度。
- 深色设备、作品图或人物可以作为少量视觉锚点，但不能让整站重新变成黑色主体。

新的气质关键词为：

`Soft / Fluid / Luminous / Airy / Editorial / Intelligent / Warm`

中文可理解为：**柔软、流动、透光、轻盈、编辑感、理性且有温度。**

此前的 `design/phase-1-blueprint.json` 仍记录旧版 BLACK / MOTION / EDITORIAL 方向，仅作为历史文件保留，在下一次进入实现前需要同步更新；从本轮起，视觉判断以本文档为准。

## 2. PPT 的可核验视觉事实

本轮重新检查了 PPT 全部 10 页，而不是只依据单张截图做推断。

### 画布与色彩

- 10 页均为 1920 × 1080 的横向画布。
- 每页基础背景均为浅灰白 `#F4F4F4`，没有使用黑色通栏背景。
- 正文主色为炭黑 `#242424`，强调标题使用深紫 `#3B2561`。
- 彩色视觉主要来自嵌入的渐变位图，不是硬边矢量色块。
- 高饱和虹彩形状带有细微颗粒；浅色背景图则以大范围模糊、低对比色雾为主。

### 字体与层级

- PPT 的实际字体为 Helvetica Now 与 Helvetica Now Bold，整体是现代无衬线体系。
- 主标题常在 80–93px 左右，由炭黑与深紫两行组合。
- 正文约 25px，字重正常，行距宽松。
- 小标题或信息标题约 35–40px。
- 紫色短下划线是反复出现的识别元素，长度克制，不演变为装饰边框。

### 构图规律

| 维度 | PPT 中的稳定表现 | 对个人网站的启示 |
| --- | --- | --- |
| 留白 | 浅色画布占据绝大多数面积 | 页面先保证呼吸感，再放置彩色氛围元素 |
| 不规则图形 | 单个体量大，经常超出画布并被边缘裁切 | 使用一主一辅的超大形状，不做小装饰贴纸墙 |
| 图形边缘 | 连续曲线、大圆弧、圆润端部 | 不出现可辨认的多边形顶点、尖角或锯齿 |
| 虹彩 | 紫、粉、青、薄荷绿柔和过渡 | 用渐变形成光感，避免生硬分段和纯色碰撞 |
| 信息排版 | 标题、短文与产品图采用明显的不对称构图 | Hero 不必绝对居中，但要留下完整阅读区 |
| 深色元素 | 主要是设备、产品图和文字 | 深色只作视觉锚点，不成为全站底色 |
| 组件 | 页面平面、编辑化，胶囊仅用于少量操作或时间节点 | 避免玻璃卡片、厚阴影和密集卡片网格 |

PPT 中的彩色自由形状本身是带纹理的图片填充，且经常用负坐标延伸到页面之外。这一点很重要：它们的效果来自“超大柔软形体被画布自然裁切”，而不是用几个角点拼出一个完整图标。

## 3. 新的专属视觉概念

### 核心叙事

**在清晰、理性的编辑版式里，注入一层柔软而有生命力的虹彩。**

这套表达适合个人网站的原因是：

- 明亮留白保证简历、经历与项目内容易读，不会被氛围吞没。
- 深紫与规整排版保留专业感和判断力。
- 流体虹彩带来个人辨识度，也能表达 AI、创造力、探索与变化。
- 圆润边缘降低距离感，让网站更开放、友好、有温度。

### 情绪边界

希望呈现的是“柔和但不幼稚，明亮但不甜腻，科技但不赛博，专业但不沉闷”。

不追求奢侈品牌式的冷峻，不追求游戏界面的刺激，也不使用常见的蓝紫霓虹 AI 模板。个人气质应来自色彩的流动、版式的呼吸和内容判断，而不是依靠黑色、故障效果或强烈动效制造高级感。

## 4. 色彩与光感

### 从 PPT 提取的基础色

| Token | 色值 | 用途 |
| --- | --- | --- |
| Paper | `#F4F4F4` | 全站主背景、正文阅读区 |
| Ink | `#242424` | 主标题、正文、导航 |
| Deep Violet | `#3B2561` | 第二行标题、短下划线、重点标签 |
| White Light | `#FFFFFF` | 渐变中心、留白与高光 |

### 网页实现时的建议虹彩色

以下色值是根据代表图建立的网页近似值，用于后续原型，不把它们当作 PPT 中的精确品牌常量：

| Token | 建议色值 | 视觉角色 |
| --- | --- | --- |
| Lilac Mist | `#D8D3FF` | 主体紫色雾光 |
| Blush Cloud | `#F3C9D0` | 温柔的人感与过渡 |
| Aqua Haze | `#C7F0EF` | 清透、呼吸感 |
| Butter Light | `#FFF1AF` | 少量暖光 |
| Mint Glow | `#D8F8D1` | 虹彩尾端与轻盈感 |

建议页面面积配比：浅灰白与白色 70%–80%，柔光渐变与虹彩形状 15%–25%，深灰与深紫 8%–12%。这些比例是视觉控制线，不要求机械相加或逐屏严格一致。

光感应像隔着磨砂材质的自然光：中心可接近白色，颜色沿大范围缓慢扩散。禁止硬色阶、彩虹条带、霓虹描边、高饱和纯色大块和黑色遮罩。

## 5. 形状系统

这是本轮最重要的修正项。**不规则不等于尖锐，个性不等于有棱角。**

### A. 虹彩流体形

参考 `02.png`、`03.png` 与 `05.png`：

- 形体像柔软的丝带、液态膜或被气流拉伸的织物。
- 可以有凹陷、分叉与收窄，但每一次方向变化都由长曲线完成。
- 端部必须圆润，凹槽必须采用大圆弧，不出现突然折断的边。
- 桌面端单个主形状可占 45–80vw，并允许 25%–55% 超出视口。
- 同一视口以一个主形状为主，最多增加一个很小的呼应形，不密集铺陈。
- 可保留参考图中的细颗粒，以增加材质感，但颗粒不能破坏轮廓的柔和度。

后续实现优先直接使用已提供的透明素材，或使用 SVG 贝塞尔曲线与柔和遮罩重绘。禁止使用 `clip-path: polygon(...)` 模拟这类形状，也禁止用带明显顶点的 CSS 多边形、星芒、箭头或碎片替代。

### B. 柔光网格背景

参考 `04.png` 与 `06.png`：

- 以白色为中心，淡黄、粉、丁香紫、青色和薄荷绿从四周缓慢进入。
- 色块边界应完全模糊，不能看出圆形渐变的明确轮廓。
- `04.png` 的横向比例适合桌面 Hero；`06.png` 的纵向构图更适合移动端裁切或竖向媒体。
- 作为完整背景时不叠加深色遮罩；文字应落在天然较白、较安静的区域。
- 作为独立面板时可使用 24–40px 的柔和圆角；作为满屏 Hero 时不必强行套进卡片边框。

### C. 明确禁用的图形语言

- 锐利三角形、闪电形、箭头形、星芒和玻璃碎片。
- 能直接数出角点的多边形轮廓。
- 轮廓突变、锯齿边、尖锐凹槽与过窄尖端。
- 同一屏出现多个小型彩色贴纸或漂浮碎片。
- 为了“科技感”加入网格扫描线、故障噪点、霓虹光框或金属高光。

## 6. Hero 设计方向

Hero 应优先把 `04.png` 或同类柔光网格作为大面积背景，而不是把深色画布作为默认答案。

### 推荐构图

- 桌面端使用接近 88–100svh 的开阔画面，保留一块宽阔、接近白色的标题阅读区。
- 主标题可使用两行无衬线大字：第一行炭黑，第二行深紫，呼应 PPT。
- 一条短而细的深紫下划线可作为稳定识别符号。
- 彩色形状从边缘进入或在背景内扩散，不从文字后方高对比穿过。
- 若后续加入人物肖像或项目设备图，只保留一个深色视觉锚点，并让它与柔光背景形成轻重对比。
- 首屏行动入口控制在一个主入口和一个次入口以内，不堆叠大量胶囊按钮。

不应在同一首屏同时出现巨大尖锐图形、人物肖像、网格、角标、多个按钮和重阴影。Hero 的记忆点应来自一块有呼吸的柔光场域，而不是元素数量。

### 响应式裁切

- 桌面优先采用 `04.png` 的横向构图，让浅色中心承担文字。
- 移动端优先采用 `06.png` 的纵向构图，或重新定义背景位置，不能简单把桌面图居中后裁掉关键色彩。
- 小屏最多保留一个可辨识的流体形，且不得侵占姓名、定位与主要入口的安全区域。
- 任何屏幕尺寸都不能依赖深色蒙层解决文字对比度。

## 7. 字体与排版

PPT 的排版依据是现代无衬线，不再把高对比衬线体作为网站的核心标题语言。

- 英文优先使用已获授权的 Helvetica Now；若无法使用，网页回退为 Geist、Helvetica Neue、Arial。
- 中文优先使用 Noto Sans SC 或 PingFang SC，保持与英文相同的理性、圆净感。
- Hero 标题建议桌面 72–112px、移动端 48–68px，字重约 650–750，行高 0.92–1.05。
- 分区标题建议桌面 44–72px，正文 16–18px、行高 1.6–1.75。
- 导航、标签与元数据建议 11–13px，可使用轻微字距，不把所有正文强制大写。
- 标题可以通过炭黑与深紫分行建立层次，不依靠描边、发光或斜切制造效果。
- 长文宽度建议控制在 680–780px，避免浅色画面因横向文字过长而失去安静感。

## 8. 页面节奏与组件语法

### 页面节奏

全站应保持浅色连续基底，在关键节点切入大幅柔光背景、虹彩流体形或一张深色人物/项目图。预计 70% 以上的滚动长度保持明亮，深色完整章节最多作为一次强调或收束，面积不超过全站约 15%。

建议首页节奏为：

1. 柔光 Hero：建立姓名、定位与视觉记忆。
2. About / Point of View：以大留白和短文本说明个人判断。
3. Selected Work：项目图作为深色锚点，虹彩只在边缘或转场出现。
4. Experience / Capabilities：采用编辑排版和细线分组，不做仪表盘式卡片墙。
5. Thoughts / Life：让粉、青、淡黄等柔和区域带出更有人感的内容。
6. Contact：以简洁浅色或一块克制的深紫收束。

### 组件边界

- 内容卡片尽量平面化，通过留白、对齐和细线区分层级。
- 图片或渐变面板可使用 24–32px 圆角，与柔和轮廓保持一致。
- 胶囊只用于明确可点击的按钮、标签或时间节点，不能成为所有内容的容器。
- 阴影应非常轻，优先使用色差和间距建立层级。
- 不使用玻璃拟态、深色浮卡、密集描边、机械网格或四角定位框。

## 9. 动效、响应式与无障碍

动效应延续“漂浮、呼吸、扩散”的感觉，而不是旋转、碰撞或快速弹射。

- 大型流体形可在 10–16 秒内缓慢漂移 8–16px，或做非常轻微的呼吸缩放。
- 柔光网格背景应静止，或只做几乎不可察觉的色场移动。
- 文字进入采用 300–600ms 的淡入和短距离上移，不做字符故障或高速翻转。
- Hover 只产生轻微亮度、位移或缩放变化，不使轮廓突然尖锐化。
- `prefers-reduced-motion` 下关闭漂移、视差和循环缩放，内容直接呈现。
- 装饰形状对辅助技术隐藏，不能承载唯一信息或阻断键盘焦点。
- 文字与背景必须保持可读对比；若某个区域过彩，应调整背景位置或增加局部白色呼吸区，而不是覆盖黑色蒙层。

## 10. 明确禁用项

| 不采用 | 原因 | 对应替代 |
| --- | --- | --- |
| 黑色主背景占据全站 | 与 PPT 的浅色、透气基底相反 | 以 `#F4F4F4` 为主，深色只作锚点 |
| `clip-path: polygon(...)` 制作主视觉 | 会产生锐角和折线 | 使用原始位图、SVG 贝塞尔曲线或柔和遮罩 |
| 大片霓虹蓝紫渐变 | 容易滑向通用 AI / 赛博视觉 | 使用低对比粉、紫、青、淡黄与白色过渡 |
| 高对比衬线大标题 | 与 PPT 的现代无衬线语言不一致 | 使用 Helvetica Now 风格的无衬线层级 |
| 玻璃拟态和卡片墙 | 破坏编辑感与留白 | 使用平面排版、细线和大间距 |
| 尖刺、碎片、箭头、星芒 | 产生攻击感和廉价动效感 | 使用连续圆滑的流体轮廓 |
| 高速旋转、强弹性、鼠标追逐特效 | 抢夺内容注意力 | 使用慢速漂浮与短距离淡入 |
| 深色蒙层覆盖柔光图 | 会让虹彩变脏、页面重新沉闷 | 把文字放在天然浅色区域 |

## 11. 第一阶段决策与下一步

本阶段已经确定：

- 网站视觉方向改为 **SOFT IRIDESCENT EDITORIAL**。
- `#F4F4F4` 是主画布，`#242424` 与 `#3B2561` 建立文字结构。
- `02.png`、`03.png`、`05.png` 定义“虹彩流体形”；`04.png`、`06.png` 定义“柔光网格背景”。
- 所有主视觉图形必须使用连续曲线和圆润端部，禁止多边形模拟。
- Hero 优先采用柔光网格背景，深色人物或项目图只作为单个视觉锚点。
- 字体回到 PPT 所体现的现代无衬线体系。
- 本轮不修改网站，只完成视觉方向确认。

进入下一阶段前应先同步更新 `design/phase-1-blueprint.json`，并把当前网站中的尖锐多边形方案列为首个移除项。随后只制作 Hero 的两种轻量原型供初审：

1. A 版：`04.png` 式柔光背景全幅呈现，标题与入口落在白色呼吸区。
2. B 版：柔光背景上增加一个 `02.png` 式的大型圆润流体形，或增加一张人物/作品图作为唯一深色锚点。

只有 Hero 的色彩、曲线、裁切与信息密度通过初审后，再向 About、Work、Experience 等板块扩展。

### 下一阶段验收清单

- 页面是否至少有 70% 的明亮画布与可见留白。
- 放大查看流体形轮廓时，是否看不到明确角点、折线或尖端。
- 源码是否没有用 `clip-path: polygon(...)` 制作主视觉。
- 柔光背景是否保留白色中心与低对比过渡。
- Hero 标题是否无需深色蒙层即可清晰阅读。
- 单屏是否只有一个主视觉重点，而不是多个装饰争抢注意力。
- 移动端是否为纵向画面重新安排裁切与文字安全区。
- Reduced Motion 下是否仍能完整、清楚地浏览全部内容。
