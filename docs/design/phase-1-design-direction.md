# 第一阶段风格设计：BLACK / MOTION / EDITORIAL

> 状态：总体视觉与交互方向已重新确定，尚未进入网页实现和逐板块线框。
>
> 核心原则：YSL 提供视觉气质，Youdoo 提供交互骨架；主体颜色为黑色，不使用黄色作为本站品牌色。
>
> 结构化蓝图：`design/phase-1-blueprint.json`。

## 1. 本轮设计结论

这不是一份“黑色版 Youdoo”，也不是对 YSL 电商页面的仿制。网站的专属方向是：

**用 YSL 式的黑色电影感、编辑排版和克制留白，承载 Youdoo 式有物理感的鼠标与滚动交互，最终服务于宋艾欣作为 AI 产品经理的作品、判断和人格。**

建议内部风格代号为 **BLACK / MOTION / EDITORIAL**，配比不是机械平均：

- 视觉氛围：YSL 65%，Youdoo 35%。
- 交互与布局：Youdoo 70%，YSL 30%。
- 内容表达：100% 基于个人真实经历与证据。

用户本轮明确提出的“黑色主体 + YSL 气质”是最新设计依据。附件提示词中实际可检索到 Youdoo 复刻要求与“黑色主标题”，没有独立的 YSL 设计章节，因此不把附件里不存在的内容当成事实。

## 2. 两个参考站分别提供什么

本轮于 2026-09-03 重新检查了 [Youdoo](https://youdooplay.com/) 与 [Saint Laurent](https://www.ysl.com/en-en)。以下是后续设计应继承的“语法”，不是要复制的品牌资产。

### Youdoo：交互骨架与场景节奏

| 观察维度 | 参考站表现 | 转译到个人网站 |
| --- | --- | --- |
| Header | 1440px 视口下为 1180 × 56px、距顶 24px的固定胶囊 | 首屏使用通栏隐形导航，向下滚动后收成 56px 黑色浮动胶囊 |
| 首屏 | 100vh，大字号标题，大幅产品视觉 | 100svh 黑色身份首屏；姓名、定位与人物/作品媒体构成一张海报 |
| 滚动 | Lenis 平滑滚动、GSAP/ScrollTrigger、Sticky/Pinned 场景 | 只在旗舰案例叙事使用固定场景；其余内容保持自然滚动 |
| 鼠标 | 页面加载鼠标相关脚本，按钮附近可见跟随与缩放的小圆点反馈 | 设计一套专属“象牙白光点 + 细环”鼠标，链接磁吸，媒体上变为 `VIEW` |
| 浏览结构 | 径向轮盘、横向图片带、Swiper 轮播 | 用于浏览案例、产物与个人侧面，不照搬游戏或商品语义 |
| 微交互 | 导航文字翻面、弹性宽度变化、媒体 Hover | 保留短促物理感，但降低回弹幅度，匹配黑色高级感 |
| 形状 | 黄色、高圆角、消费电子式卡片 | 只保留少量胶囊控件；全屏媒体和编辑图片改为直角 |

Youdoo 的价值是“让页面像一个可探索的产品”。黄色、紫色、儿童家庭画面、圆润商品卡和购买语义不属于个人网站。

### YSL：视觉气质与编辑秩序

| 观察维度 | 参考站表现 | 转译到个人网站 |
| --- | --- | --- |
| 首屏 | 1440 × 900 的完整视口影像，黑白标识悬浮在媒体上 | 使用全屏低饱和肖像或项目蒙太奇，文字压到边缘或底部而不是堆满中央 |
| Header | 约 80px 高、通栏透明、12px 左右大写导航，Logo 居中 | 首屏导航透明；采用小号大写英文与克制中文，不复制 YSL Logo 排版 |
| 场景切换 | 滚轮在全屏广告场景间切换，页面本身几乎不产生普通位移 | 旗舰案例可做“近似分页”的视觉换场，但保留明确滚动进度和退出路径 |
| 编辑画廊 | 白色场景中双列竖幅图片，1440px 下单图约 534 × 667px | 用黑/米白反差章节展示研究框架、原型和生活照片 |
| 字体与标签 | Helvetica 系无衬线、约 12px 大写标签、极少文案 | 导航、类别和元数据使用小号无衬线；大标题可加入高对比衬线以形成个人辨识度 |
| 影像 | 全幅视频/图片、低干扰控制、底部居中的名称与 CTA | 项目标题和角色信息贴边呈现；视频必须有 Poster、播放/暂停和静音状态 |
| 形状与色彩 | 黑白为主，直角，几乎没有装饰卡片 | 黑色成为全站主体；圆角只出现在功能控件，不把内容装进“气泡” |

本轮没有在 YSL 首页检测到需要继承的全局自定义鼠标。鼠标语言来自 Youdoo，YSL 提供的是克制程度：鼠标可以有存在感，但不能像游戏特效一样抢走内容。

## 3. 专属视觉概念

### 品牌定位

**宋艾欣 / Shareen Song — AI 产品经理**

核心表达继续采用：

> 把复杂 AI 能力，做成有边界、可验证、可交付的产品闭环。

这句话对应个人经历中最稳定的能力交集：产品研究与定义、Agent 与异常边界、真实业务交付。

### 气质关键词

`Cinematic / Precise / Independent / Intelligent / Sensual / Human`

- **Cinematic**：黑色空间与全幅影像先建立情绪。
- **Precise**：网格、细线、元数据与证据状态建立专业可信度。
- **Independent**：不套用常见蓝紫色 AI 模板，也不依赖品牌 Logo 借势。
- **Intelligent**：动效展示信息关系，不只是装饰。
- **Sensual**：使用肖像、材质、光影与留白表达个人风格，但保持职业边界。
- **Human**：心理、社区、古筝、瑜伽、书法和研学构成人感，不让网站只剩项目截图。

## 4. 色彩、字体与材质

### 黑色为主体

| Token | 色值 | 用途 |
| --- | --- | --- |
| Black Canvas | `#050505` | 页面主背景与首屏 |
| Charcoal | `#111111` | 浮层、收缩导航、内容分区 |
| Deep Gray | `#181818` | 功能卡片与媒体占位 |
| Ivory | `#F3F0E9` | 主要文字与米白编辑章节 |
| Pure White | `#FFFFFF` | 极少量高亮、图标、焦点状态 |
| Muted | `#9A9A95` | 次要说明与时间信息 |
| Silver | `#C5C5BF` | 线性图形、数据和技术细节 |
| Oxblood | `#5A1018` | 约 3%–5% 的个人强调色 |

黄色不进入本站设计令牌。大面积紫色渐变、霓虹蓝、玻璃拟态和彩色科技光效也不采用。酒红只用于项目编号、鼠标状态、进度或极少量聚焦信息，不作为大面积背景。

### 字体层级

- 导航、按钮、类别、数字：Helvetica Neue / Arial / Noto Sans SC，11–13px，大写英文配宽字距。
- 正文：Noto Sans SC / PingFang SC，桌面 16px，行高约 1.7；长文控制在 720–800px。
- 表达型大标题：Cormorant Garamond / Noto Serif SC / Songti SC，允许 56–152px 的响应式字号。
- 大标题不承担长解释；角色、时间、证据状态回到小号标签和正文。

### 形状与材质

- 全屏媒体、肖像和双列编辑图：直角或最多 2px 圆角。
- 功能卡片、截图容器：12px 圆角。
- Header 收缩态、筛选器和状态标签：999px 胶囊，但数量要少。
- 背景可叠加 1%–2% 的静态颗粒和轻微暗角；不使用持续流动噪点。
- 阴影几乎不可见，以亮度、遮罩和层级替代“浮卡片”效果。

## 5. 背景与影像系统

网站以三种场景交替，形成呼吸，而不是从头黑到底：

1. **Black Cinema**：约占 70%。近黑背景、全屏肖像/视频、象牙白文字；用于身份和旗舰案例。
2. **Ivory Editorial**：约占 20%。米白背景、黑字、双列竖幅图或 800px 长文；用于方法、证据和关于。
3. **Oxblood Focus**：不超过 10%，且多数只是局部线条、编号或状态；用于关键判断和交互反馈。

人物影像建议为黑白或低饱和、硬光与留黑充分的编辑肖像。产品素材不直接堆截图：Dashboard、PRD、流程图和原型应被重新裁切、编号，并像时装 Lookbook 一样成组编排。不同经历可有轻微色温差，但仍属于同一个黑色系统。

背景切换采用黑场、遮罩或曝光变化，不使用黄色色块转场。视频优先 8–12 秒静音循环，同时提供静态 Poster；重要内容不能只存在于视频中。

## 6. 总体布局语法

本阶段只确定页面骨架，不细化每个板块：

- **Identity Hero**：100svh 黑色电影首屏；桌面为全幅媒体，小号身份信息贴近底部，大标题在进入时完成一次排版揭示。
- **Selected Work Scenes**：三个 S 级案例作为首页主线。每个案例可占一个视口，用 Youdoo 的固定滚动与 YSL 的全幅影像完成切换。
- **Case Index**：从沉浸场景退出后，进入可快速浏览的项目索引；可使用环形选择器或横向媒体轨道，但必须同时提供普通列表入口。
- **Proof Editorial**：切换到米白背景，以双列图片、800px 文字和细线展示方法、证据与贡献边界。
- **Human / Contact**：回到黑色，使用肖像、生活片段和极简联系信息收束，不做传统“大按钮销售页”。

全站主内容宽度以 1180px 为桌面基准，长文约 800px。宽屏影像允许触达视口边缘。项目详情遵循“情绪首屏 → 决策与过程 → 证据 → 复盘”的统一节奏，但不强制每个案例具有完全相同的视觉模板。

## 7. 交互方式清单

| 交互 | 表现方式 | 使用位置 | 降级与边界 |
| --- | --- | --- | --- |
| 鼠标跟随 | 12px 象牙白实心点 + 36px 细环，以插值产生轻微延迟 | 全站桌面端 | 仅 `pointer: fine`；触屏不渲染；原生指针在表单和正文区保留 |
| 磁吸链接 | 光点向导航/CTA 中心轻微偏移，文字产生 2–4px 位移 | Header、案例入口 | 键盘焦点使用清晰描边，不依赖 Hover |
| 情境鼠标 | 媒体上扩为 `VIEW`；可拖拽轨道上变为左右箭头 | 案例封面、横向轨道 | 不遮住标题，不成为唯一操作提示 |
| 平滑滚动 | 低阻尼、快速收束，保留系统滚动方向 | 桌面主页面 | 不改变浏览器可达性；Reduced Motion 下关闭 |
| 全屏换场 | 滚轮推进媒体、标题和背景曝光变化 | 首页旗舰案例 | 只做一组；有进度、跳过和退出；移动端自然流 |
| Sticky 案例 | 媒体固定，事实、角色和结果按滚动逐步进入 | 重点案例摘要 | 每步文案短；不把长文锁在视口内 |
| 环形案例轮 | 项目封面沿大半径移动，当前项放大并显示编号 | Case Index 可选模式 | 同步提供列表视图；不自动高速旋转 |
| 横向媒体轨 | 拖拽查看原型、产物、研学与个人照片 | 项目详情、About | 触屏原生滑动，键盘可操作，首尾状态明确 |
| 导航翻面 | 文字在约 480ms 内垂直翻面 | 桌面 Header | Reduced Motion 下改为颜色变化 |
| Header 变形 | 首屏为 80px 通栏透明层，滚动后收成 56px 黑色胶囊 | 全站 | 不能因收缩造成布局跳动；小屏始终简化 |
| 图片显影 | Hover 时图片放大 1.015–1.03，遮罩变浅，标题上移 | 项目索引 | 动画 240–360ms，不做强烈透视 |
| 页面转场 | 黑色幕布或标题 Mask 在 450–650ms 内完成 | 项目列表到详情 | 页面可直接打开；不伪装加载时间 |
| 全屏菜单 | 黑底米白字，栏目分层展开，附简历与联系入口 | 移动端 | 焦点锁定、Esc 关闭、关闭后焦点归位 |

最重要的限制是：**滚动特效不能妨碍招聘者快速跳读。** 首页只有一次核心沉浸体验，所有证据和案例必须可通过普通链接直接到达。

## 8. 响应式与无障碍原则

| 范围 | 设计变化 |
| --- | --- |
| ≥1440px | 1180px 内容网格、100svh 场景、鼠标跟随、Pinned 案例、双列编辑画廊 |
| 1024–1439px | 32–48px 边距，缩短固定滚动距离，保留双列和横向轨道 |
| 768–1023px | 取消环形强透视，案例转两列/纵向，Header 简化 |
| 375–767px | 16px 边距、单列自然滚动、无自定义鼠标、无强制滚动捕获、全屏菜单 |

- `prefers-reduced-motion` 下关闭平滑滚动、磁吸、Pinned、视差、自动轮播和大幅 Mask，只保留淡入或直接呈现。
- 所有视频必须能暂停；自动播放必须静音。
- 黑色背景正文采用 `#F3F0E9`，次级文字仍需满足可读对比度。
- 交互支持键盘，焦点状态不可被自定义鼠标替代。
- 不做全站 Scroll Snap，不劫持浏览器返回，不依赖鼠标才能看到内容。

## 9. 素材与内容准备

### P0：进入线框前必须准备

1. 一组适合黑色背景的高分辨率肖像：正面半身、侧面、环境照各至少一张，长边建议 2400px 以上。
2. 竞品 Agent：脱敏 Dashboard、工作流、证据链、异常案例。
3. iGarden：研究框架、产品生态图、核心流程和控制 App 原型。
4. AI 数字人教育：产品界面、部署或宣讲现场，移除客户敏感信息。
5. 每个 S 级项目的一句话问题、一项关键判断、一条可公开证据和个人贡献边界。

### P1：增强个人气质

1. 8–12 秒项目与人物蒙太奇及静态 Poster。
2. VibeCoders、欧洲研学、校园或社区活动照片。
3. 古筝、瑜伽或书法的克制生活影像。
4. `SHAREEN SONG / 宋艾欣` 自有字标探索，不模仿 Saint Laurent 标识。

不得发布 Youdoo 或 YSL 的 Logo、商品图、模特图、视频、字体文件和营销文案。参考站只用于研究布局与交互语法，最终素材必须自有、获授权或采用明确可商用来源。

## 10. 第一阶段决策与下一步

本阶段已经确定：

- 黑色 `#050505` 是网站主体，不再保留黄色候选方案。
- YSL 决定气质：电影影像、黑白反差、微型标签、编辑留白、直角媒体。
- Youdoo 决定体验：鼠标跟随、平滑滚动、固定场景、环形/横向浏览和导航翻面。
- 三个 S 级案例仍是内容核心，但本阶段只定义整体节奏，不细化每个板块。
- 自定义鼠标和滚动叙事必须有触屏、键盘与 Reduced Motion 降级。
- 网站不复制两个品牌的素材、Logo 或商业功能。

下一阶段建议产出一张桌面首页低保真线框和一张移动端内容顺序图，并同时完成 P0 素材可公开性盘点。线框确认后，再定义逐板块文案、组件与动效参数。
