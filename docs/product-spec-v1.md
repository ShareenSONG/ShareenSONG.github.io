# 个人网站产品需求文档 v1

> 状态：已确认并进入 MVP 实现；默认中文与全站中英切换需求已确认，待页面实现。
>
> 更新时间：2026-09-10。
>
> 产品定位：个人作品集 + 数字名片。
>
> 视觉方向：柔光虹彩编辑感（`SOFT IRIDESCENT EDITORIAL`），以[视觉设计规范](design/phase-1-design-direction.md)为准。

## 1. 网站目标

网站用于展示个人背景、教育与工作经历、代表性项目、项目判断、个人形象、生活方式，以及对 AI、产品和科技的长期思考。

文章正文不存储在网站内部。站点只维护标题、日期、标签、简介与外部链接，文章发布在 GitHub、技术博客或其他外部平台。

## 2. 目标受众与任务

| 受众 | 首要任务 |
| --- | --- |
| HR / 招聘人员 | 快速确认身份、教育、工作、项目、AI/产品能力、简历与联系方式 |
| 招聘经理 / 产品负责人 | 深入检查问题定义、研究、洞察、产品判断、角色、结果与反思 |
| 同行 / 开发者 / 朋友 | 查看 AI 实验、思考、GitHub、兴趣与个人生活 |

体验原则：**首页快速了解我，项目页深入了解我的能力，生活页面了解我这个人。**

## 3. MVP 页面与路由

| 路由 | 页面职责 | MVP 状态 |

## 4. 首页内容契约

### 首屏介绍

- 宋艾欣 / Shareen Song。
- AI 产品 / 产品 / 增长。
- 中文定位：`探索 AI、产品与人类行为如何交汇。`
- 英文模式对应定位：`Exploring how AI, products and human behavior come together.`
- 深圳 / 香港、邮箱、GitHub、简历。
- 使用个人影像和浅色柔光编辑式排版，遵循视觉设计规范。

### 关于我

用短文说明计算机与数据基础、为什么做产品、对 AI 与人的兴趣，以及以研究、边界和证据为核心的工作方式。避免长篇自传。

### 经历

使用编辑式时间线，而不是简历表格。每条只展示组织、角色、时间、地点与一段核心说明；详细职责进入项目页。

### 精选项目

MVP 使用经历目录中证据最完整的三个 S 级项目：

1. iGarden 体感游戏。
2. 竞品监控 Agent。
3. AI 数字人教育产品。

原需求中的 `Amazon Data Platform` 是示例名称，在已确认经历目录中没有对应的独立项目，因此不虚构该案例。竞品监控 Agent 的 SQLite 数据层作为其项目系统的一部分呈现。

### 思考

只提供外部索引。GitHub 使用已确认链接；尚未发布的文章在中文模式标记为“撰写中 / 草稿”，英文模式标记为 `WRITING / DRAFT IN PROGRESS`，不创建空白详情页或虚假外链。

### 生活预览与联系我

生活预览使用少量旅行与研学照片导向 `/life`。联系我区域只保留清晰的邮箱、GitHub 和简历入口。

## 5. 项目详情模板

每个项目统一回答：

`背景 → 问题 → 研究 → 洞察 → 产品决策 → 解决方案 → 我的角色 → 成果 → 反思`

英文模式使用对应标题：`Context → Problem → Research → Insight → Product Decision → Solution → My Role → Outcome → Reflection`。

详情页规则：

- “问题”必须解释真正的问题，不从功能列表开始。
- “研究”与“洞察”分开，洞察必须能推动后续决策。
- “产品决策”说明取舍、优先级、约束和判断。
- “我的角色”明确个人贡献与团队边界。
- “成果”使用“已上线 / 内部使用中 / 方案阶段 / 已测试”等真实状态，英文模式使用对应英文。
- “反思”说明局限和重做时会改变的事情。
- 重要数字旁保留成果口径与归属边界，避免把团队结果、问卷反馈或方案状态包装成个人因果成果。

## 6. 生活页面

生活页面不承担招聘转化，主要依靠影像和短文字展示：

- 旅行与城市观察。
- 社区活动与协作。
- 古筝十级、11 年瑜伽、书法与电影。
- 自然、科幻、游戏、AI 和科技兴趣。
- 少量个人趣事。

原始照片保留在本地 `photo/`，不进入 Git；站点只提交移除元数据并压缩后的发布版本。

## 7. 导航与全站语言切换

### 7.1 导航

桌面端默认中文导航：

`宋艾欣 / 项目 / 经历 / 思考 / 关于我 / 生活 / 简历 ↗ / 中 / EN`

英文模式对应导航：

`Shareen / Work / Experience / Thoughts / About / Life / Resume ↗ / 中 / EN`

移动端：

- 紧凑顶部导航 + 菜单按钮 + 中英切换控件。
- 菜单使用全屏层，配色遵循视觉设计规范。
- `Escape` 可关闭，按钮暴露 `aria-expanded` 状态。
- 触屏不渲染自定义鼠标。

### 7.2 默认语言与内容范围（已确认，待实现）

- **仅支持简体中文（`zh-CN`）和英文（`en`）**，不增加其他语言选项。
- **首次访问、无有效语言偏好时默认中文**，包括直接打开任意子页面；不根据浏览器或系统语言自动切换英文。首次可见内容即为中文，避免先显示英文再切换。
- 中文是全站默认表达：导航、标题、正文、按钮、项目详情、思考索引、生活页面、页脚、404 页面、图片替代文本、无障碍标签及页面标题和描述均使用中文。
- 仅必要的英文单词保留原文，例如 AI、GitHub、品牌与产品专名、技术缩写、代码、网址和邮箱。常规栏目、操作与状态必须中文化，例如 Work → 项目、Resume → 简历、Contact → 联系我，不以大段英文作为中文页面的默认文案。
- 站内内容维护中英文两个完整版本，译文保留相同的事实、数字、项目状态与贡献边界，不依赖实时机器翻译，也不把缺失的中文文案直接用英文填补。
- 外部文章和简历 PDF 的原始语言不随控件自动翻译；站内入口、摘要与说明跟随所选语言，必要时标明目标内容语言。现有简历文件继续使用，仅在提供真实对应版本后再切换文件。

### 7.3 切换控件与交互（已确认，待实现）

- **所有页面右上角显示 `中 / EN` 两项语言切换控件**，位于顶部导航右侧，清晰标识当前语言；该控件是全站共享功能。
- 移动端在顶部保留可见的中英切换入口，无需先打开菜单，且不与菜单按钮重叠。
- 选择 `EN` 后全站使用英文，选择“中”后恢复中文；重复选择当前语言不改变页面状态。
- 切换后保持当前页面、项目与锚点，不跳回首页，并尽可能保持当前阅读位置。
- 语言选择保存在当前浏览器本地，刷新、站内跳转和再次访问时沿用用户上次选择；没有有效记录时恢复默认中文。只有用户主动选择英文后才进入英文模式。
- 浏览器本地存储不可用时，仍能完成当前页面的语言切换；后续整页加载无可读取偏好时使用中文，不因存储失败阻断页面访问。
- 控件支持键盘操作与可见焦点，向辅助技术说明当前语言和切换目标；页面语言标记随选择更新为 `zh-CN` 或 `en`。
- 中英文布局分别适配桌面与手机，不因文字长度变化造成导航重叠、按钮截断或内容溢出。

## 8. 内容与视觉原则

**简历说明我做过什么，作品集解释我为什么这样做。**

- 使用 `#F4F4F4` 浅灰白主体、`#242424` 深灰文字和 `#3B2561` 深紫强调，配合柔光虹彩；具体排版与动效以视觉设计规范为准。
- 个人照片、真实数据和项目判断优先于装饰。
- 桌面端使用克制的悬停反馈，具体动效遵循视觉设计规范。
- 移动端采用自然文档流，不捕获滚轮，不强制 Scroll Snap。
- `prefers-reduced-motion` 下关闭自定义鼠标和大幅动画。
- 不复制 Youdoo 或 YSL 的 Logo、图片、视频和营销文案。

## 9. 非目标

第一版不制作后端、数据库、CMS、登录、评论、AI 聊天机器人或站内博客。所有页面为静态内容；仅在浏览器本地记住语言偏好，不需要服务端持久化数据。不扩展中文、英文以外的语言，也不提供实时机器翻译。

## 10. 验收标准

### 语言功能验收（待实现后验证）

- 清除语言偏好后，分别直接打开首页、项目列表、项目详情、思考、生活与 404 页面，首次内容均为中文；即使浏览器语言为英文也不例外。
- 中文模式覆盖第 7.2 节所列全部界面文案及页面元信息，除必要英文专名与术语外，没有遗留英文栏目、按钮或正文段落。
- 桌面与手机每个页面的右上角均可直接操作 `中 / EN`，当前语言明确可辨；全站仅有中英两种选项。
- 在项目详情或带锚点的页面切换为英文，再切回中文，内容语言正确且仍停留在同一页面与锚点。
- 主动切换英文后刷新、跨页面浏览和再次访问仍为英文；切回中文后同样保持中文。清除记录或记录无效时恢复中文。
- 本地存储不可用时，当前页面仍可切换语言，整页加载按默认中文规则处理。
- 两种语言均支持键盘切换、正确的页面语言标记与无障碍名称；桌面和手机没有文字溢出或控件重叠。
- 中英文内容的事实、数字和项目状态一致；外部内容及 PDF 保持原文件语言，入口说明准确。

### 通用验收

- 首页可以在短时间内回答“宋艾欣是谁？”。
- 三个精选项目可进入统一结构的完整详情页。
- 经历、思考、生活、联系我与简历均可访问。
- 所有外链在新窗口打开并使用安全的 `rel` 属性。
- 手机端可完整访问内容，菜单可操作，不依赖 Hover。
- 自定义鼠标仅在精确指针且非 Reduced Motion 环境启用。
- 全部测试、Lint、TypeScript 检查与生产构建通过。
- 社交预览使用个人网站标题与视觉，不再显示 Style Demo 元数据。
