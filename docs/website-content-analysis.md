## 一、整体判断

宋艾欣最有辨识度的定位不是“会使用 AI 工具的产品经理”，而是：

> 能把复杂的 AI 与软硬件能力，转化为有边界、可验证、可交付的产品工作流。

现有经历可以形成一条连续的成长主线：计算机与数据技术基础 → AI 教育产品商业交付 → 信息技术管理与跨学科学习 → AI Agent、软硬件产品和海外场景研究。网站需要优先证明三件事：

1. 能发现与定义真实问题，而不只执行需求。
2. 能把 AI 能力拆成产品流程、规则边界、异常闭环和验收标准。
3. 能把方案推进到原型、数据产物、跨团队评审或实际业务交付。

## 三、建议的网站板块

### 1. 首页 Hero

- 一句话定位：围绕“AI 产品闭环、复杂系统产品化、可验证交付”表达，不堆叠工具名。
- 只放 3–4 个经得起追问的关键事实，例如高校产品落地、竞品监控范围、完整 PRD/原型和跨市场试跑。
- 入口优先级：查看案例 → 了解经历 → 联系我。

### 2. 精选案例

建议首期只做三项，保证深度：

1. **竞品监控 Agent 与 Dashboard**：突出工作流、规则/LLM 边界、证据链、Bad Case 和跨品类复用。
2. **iGarden Motion Game**：突出海外研究、方向判断、软硬件边界、游戏玩法与控制 App 原型。
3. **AI 数字人教育产品**：突出从用户需求到部署、商业验证和标准化交付的完整链路。

每个案例使用统一结构：背景与问题 → 我的角色 → 研究/约束 → 关键决策 → 方案与流程 → 验证 → 结果 → 复盘与边界。相比平铺职责，这种结构更容易让招聘方判断真实贡献。

### 3. 项目实验室

放置 OpenClaw 安全、MindCare、Sasa Beauty、Spark 等 A/B 级项目。它们用于证明能力宽度，不与真实工作项目抢首页注意力。后续可以逐步加入原型、实验截图、脱敏报告和代码链接。

### 4. 经历时间线

按时间串联教育、工作、项目和国际交流。时间线承担“完整履历”功能，首页案例则承担“核心能力证明”功能，两者不要重复大段文案。

### 5. 能力地图

不要制作普通的技能进度条。建议按真实工作任务组织：

- 研究与定义：用户研究、竞品分析、需求优先级、PRD、原型。
- AI 产品化：Agent 工作流、Prompt、规则与 LLM 边界、异常兜底、安全与权限。
- 数据与验证：SQL/Python、数据链路、Dashboard、A/B 测试、可用性测试。
- 交付与协作：Roadmap/WBS、跨团队评审、ToB/ToG 方案、招投标和验收。

每个能力应链接到至少一个案例证据，避免孤立罗列工具。

### 6. 观察与成长

用短内容承载 TechXPlore、上海交大交换、VibeCoders 和行业观察。这一板块可以展示学习速度、国际视角和对 AI 产品趋势的持续判断。

### 7. 网站之外的我

古筝十级、长期瑜伽、书法和电影可以形成克制的个人化板块。它们不是简历尾注，而是视觉风格与内容气质的来源：秩序感、长期主义、身体感知和叙事审美。

## 四、旗舰案例的叙事重点

### 竞品监控 Agent

核心不是“用了 OpenClaw/Hermes”，而是把不稳定的网页调研变成可追溯的产品系统：数据源 → 快照 → 事实抽取 → Diff → 事件 → 报告 → 业务交付。适合用流程图、异常分支、Dashboard 截图和一条脱敏事件案例呈现。

已确认正式监控 20+ 品牌、服务公司内部 200+ 用户，SQLite 数据中台真实写入业务数据；约 30% 工时节省来自通过钉钉在公司内部发放的问卷调查。案例公开时需要把内部问卷结论标明为自报反馈，并对数据库、Schema、查询结果和 Dashboard 全部脱敏。

### iGarden Motion Game

核心是“从市场不确定性到可评审产品方案”。可以把研究如何影响方向决策、Camera 能力如何转成玩法、App 如何处理连接与异常三个层次串联起来。适合展示研究框架、产品生态图、核心 User Flow 和原型。

已确认联络 114 家游戏工作室和 Steam 游戏开发者，并与北美多家游戏工作室进行会议交流。仍需避免把方案评审写成上线结果，或把联络和会议交流延伸为已签约、已合作、已完成游戏接入。

### AI 数字人教育产品

核心是“真实商业环境下的 0→1 与规模化交付”。这是最能平衡产品、技术、方案与业务结果的案例。应区分 5 所实际产品落地、15 所方案覆盖和 1800 万元项目回款支撑三个不同口径。

## 五、已确认口径与保留补证项

原有九项内容冲突已由本人于 2026-09-03 统一口径：

1. 香港浸会大学专业排名使用前 5%。
2. 竞品 Agent 面向公司内部 200+ 用户；约 30% 工时节省来自通过钉钉在公司内部发放的问卷调查。
3. SQLite 数据中台真实写入业务数据。
4. 品牌范围只写正式监控 20+ 品牌。
5. 已联络 114 家游戏工作室和 Steam 游戏开发者，并与北美多家游戏工作室进行会议交流。
6. MindCare 用户研究样本使用 N=60。
7. Sasa Beauty 的 N=158 为全部研究样本，不表述为 158 次一对一深访。
8. VibeCoders 使用 5 场、累计 1000+ 人的口径。
9. 百科荣创相关方案覆盖使用 15 所高校，并与 5 所产品实际落地区分。

数字口径已经解决，但“可写”不等于“材料可以直接公开”。进入网站制作前仍建议留存：排名或奖学金证明、脱敏问卷统计、脱敏 SQLite Schema 与数据链路、正式品牌清单、联络与会议记录、研究报告样本说明、活动清单，以及 15 所高校的落地/方案覆盖分类。它们用于应对追问与内部核验，不一定展示在网页上。

## 六、公开边界与隐私

- 手机号、私人邮箱、政治面貌和内部文件绝对路径不进入内容目录。
- 公司内部报告、截图、数据库和 Dashboard 只有完成脱敏并获得可公开许可后才能展示。
- 证据不足的数字可以暂存于内部目录，但不能进入首页、SEO 文案或公开案例。
- 预测值、目标值和内部问卷结果必须明确标注其性质，不能包装成已实现业务结果或因果结论。

## 七、下一步建议

下一轮先确定网站的核心受众和首页目标，再为三个 S 级案例各挑选 3–5 份可公开或可脱敏的材料。完成证据挑选后，再进入视觉风格、页面信息架构和技术栈设计，会比直接开始写页面更稳。
